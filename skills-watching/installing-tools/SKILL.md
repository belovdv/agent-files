# Before installation

Make a proportionate supply-chain trust check before installing a third-party tool. Check that the source and package identity match the intended project, and inspect relevant installation behavior for obvious malicious activity.

Scale the check to the tool and its access. Report material concerns before proceeding. This is a preliminary trust check, not a full security audit or certification of safety.
