# History and workflow audits

Define the question, sample, and coverage. Distinguish listed summaries, fetched history, and actually inspected content. Large or truncated outputs do not establish complete review.

Reconstruct chronology before drawing conclusions. Separate user instructions, agent claims, observed actions, verified artifacts, and reviewer inference. Determine the latest objective before assessing an ending; earlier completion does not settle a later request, and silence is not acceptance or failure.

Follow important corrections across related artifacts and the affected diff, including new/untracked files and discovery metadata. Verify current state before treating a historical observation as still true. Do not generalize a workspace-specific constraint into a universal policy.

For patterns, provide examples and counterexamples where available. Distinguish one incident from recurrence and user-reported experience from independently observed evidence. Avoid causal claims about model quality or harness behavior that the sample cannot support.

When delegating evidence collection, request ordered source/turn references, short excerpts, coverage limits, and relevant final exchanges. Check consequential findings against the source before adopting them.

Deliver findings with evidence, uncertainty, and practical changes. Consider user behavior, agent guidance, and workspace organization; prefer the least burdensome effective remedy.

For reflection on conversations, use the existing `reflect-conversation` workflow for its detailed procedure. This file covers shared evidence discipline, not a replacement reflection process. Updating inspected configuration or applying recommendations requires separate authorization.
